# Keputusan terkunci (Grill)

1. Scope MVP = B: alur pasien inti (assessment Sovia → pilih klinik → prep konsultasi → ringkasan+rencana → check-in → progress) + konsol dokter lengkap (SOAP, skin analysis, resep). Resep/SOAP hanya oleh profesional; Sovia tidak ikut menulis. Konsol dokter: audit log + tanda tangan profesional pada rencana.
2. Multi-tenant sejak awal: clinic_id di semua data klinis, isolasi Postgres RLS; DrMetz = tenant pertama. Peran: patient, professional, clinic_admin, aevia_admin.
3. Identitas = akun terpisah per klinik (user unik per clinic_id + email; email sama boleh di klinik lain). Tidak ada berbagi data lintas klinik. Consent tetap dicatat per akun (assessment/rekam medis/foto/Body Type). Konsekuensi: riwayat & progress per klinik. Skema disiapkan kolom `global_subject_id` nullable agar bisa ditautkan nanti (tanpa fitur aktif).
4. Stack: monorepo pnpm+Turborepo (apps/api, web, console, mcp; packages/core Zod). Fastify+TS, OpenAPI dari Zod. Supabase (Postgres+RLS, Auth OTP, Storage foto), Drizzle. Next.js+Tailwind token AEVIA. Hosting semua di Vercel (API sebagai Vercel Functions). Test Vitest + Playwright.
5. Sovia: default mode SKRIP (deterministik, tanpa API key). Mode LLM (Claude via LLMProvider, bisa diganti) aktif hanya bila API key diisi + toggle per klinik dinyalakan. Guardrail: baca data pasien sendiri saja; tidak tulis SOAP/resep/rencana (output = draft); filter kata terlarang; deteksi darurat → arahkan ke layanan medis; label "Sovia adalah AI".
6. Integrasi: REST API v1 (OpenAPI, API key per klinik + OAuth client-credentials), webhook keluar HMAC (assessment.completed, plan.approved, checkin.submitted, progress.updated), MCP server (tools read + write terbatas; tak pernah tulis resep/rencana; izin klinik + audit). Target MVP: KlinikSistem + BeautyCode saja (kedua app sudah ada). Konektor.id & DrMetz Ecosystem di luar scope.
7. Brand: hex PDF v1.0 (#0B1F3A, #C9825A, #071426, #F7F4EF, #E9DDD2, #697386); tagline "Guidance for Better Aging."; screenshot = acuan alur/layout, reskin, klaim terlarang dihapus, harga per klinik. Brand mode per klinik: `cobrand` (logo klinik + "powered by AEVIA", token AEVIA) atau `whitelabel` (logo, warna, font, nama/avatar asisten, custom domain milik klinik; AEVIA tidak tampil di UI pasien, hanya di syarat & ketentuan). Warna klinik dicek kontras WCAG AA.
8. Out of scope: pembayaran/checkout (hanya permintaan program), video call bawaan (link Meet/Zoom), analisis foto AI/multi-spectral (skor manual + foto + heatmap/anotasi sederhana), Body Type, app native (PWA), Konektor.id, Ecosystem.
